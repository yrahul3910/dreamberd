# DreamBerd

This is a work-in-progress implementation of a [DreamBerd](https://github.com/TodePond/GulfOfMexico) (aka Gulf of Mexico) parser in Rust. The code follows the book "Crafting Interpreters".

## Specification

The original specification is preserved in [SPECIFICATION.md](docs/SPECIFICATION.md). However, the original spec is at times vague or self-contradictory, so it had to be clarified while preserving the original chaotic spirit; these deviations from the spec are documented in [DEVIATIONS.md](docs/DEVIATIONS.md).

For now, these two documents should be taken as the reference for what is being implemented, and other documents such as the grammar are work-in-progress like the rest of the repo.
